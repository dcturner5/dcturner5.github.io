2D Minecraft

Dalton Turner

Overview

This is a 2D recreation of Minecraft built with JavaScript for the web browser. You can mine blocks, craft, smelt, use some of the redstone mechanics, and mess with water and sand physics.

Controls

A: Left, D: Right, Space: Jump, E: Inventory

Left click: Break blocks, Right click: Place/Interact with blocks
